## About

I'm a junior web developer with a thing for hardware. I build the web side with HTML, CSS and JavaScript, and the device side with C++ on ESP32-S3 boards.

The two meet in dashboards that control LEDs, an RFID reader with OLED output, and a chat room that works over local WiFi without internet.
