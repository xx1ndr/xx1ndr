## 01 // ABOUT ME

I'm a junior web developer who prefers the hardware side of things. I build responsive, accessible interfaces with **HTML, CSS and JavaScript** — and I ship **ESP32 projects** where the browser becomes the control panel for the device.

My work so far runs end to end: firmware in **C++**, a **web dashboard** on top, and everything wired together over **WiFi**. From LED control from a browser to an offline chat room that needs no internet, I like projects where software and hardware meet.
